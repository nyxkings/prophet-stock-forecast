Research objectives

Objective (a)

Design a model for predicting asset price movement using Prophet forecasting and Modern Portfolio Theory (MPT).

Objective (b)

Implement and evaluate the system so investors can select a best combination of investments that balances expected return with market risk.

Portfolio universe: 12 US equities — AMD, MSFT, AAPL, TSLA, AMZN, NVDA, META, GOOG, TSM, JPM, NFLX, PLTR.

The problem

  • Investors need forecasts and a disciplined way to turn forecasts into weights.
  • Raw predicted returns alone ignore correlation and portfolio risk.
  • Equal-weight or gut-feel allocations do not exploit forecast information systematically.
Solution: μ from Prophet · Σ from history · optimise Markowitz utility

System pipeline

yfinance→ Preprocess→ Prophet→ MPT optimiser→ Supabase→ Streamlit UI
  • Next-day price forecasts with US holiday effects
  • Expected returns μ = (P̂ − P₀) / P₀
  • Covariance Σ from last 252 trading days only
  • Constraints: weights sum to 1; 5% ≤ wᵢ ≤ 100%; λ = 5
  • Daily automation via GitHub Actions; live dashboard for analysis

How investors get the “best combination”

Shown in the Streamlit dashboard · Overview tab

  • Pie chart + Weight (%) — recommended allocation from Markowitz optimisation
  • Return (%) — Prophet forecast signal per ticker
  • Efficient Frontier — min-variance vs max-Sharpe alternatives
  • Risk & sector tabs — VaR, CVaR, Sharpe, diversification
Maximise: μᵀw − (λ/2) wᵀΣw  |  Σwᵢ = 1,   wᵢ ≥ 0.05

Limitations

  • One-day-ahead forecasts only — not multi-horizon
  • 5% floor on 12 assets shrinks the feasible set (corner solutions common)
  • Technology sector can dominate despite asset-level floors
  • No transaction costs, taxes, or slippage in the optimiser
  • Full walk-forward backtests are computationally heavy (Prophet × 12 × many dates)
  • Illustrative research system — not financial advice

Conclusions

  • Delivered a working Prophet + MPT pipeline from data to dashboard
  • Production short-horizon MAPE of 4.31% meets the <5% threshold
  • Investors see a concrete recommended mix via optimal weights in the UI
  • Risk, sector, and evaluation tooling support transparent decision support
